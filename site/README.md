# Grace Adjeli Portfolio

Author: Grace Adjeli

A responsive portfolio for AI Governance Engineering grounded in DevOps, cybersecurity, and agile delivery. The primary message is Governance at Execution™ with Governance Holds at Execution as the subtitle.

## Stage 1 demonstration

The AI Execution Governance project uses synthetic information only. It demonstrates PERMIT, HUMAN REVIEW, and BLOCK decisions, independent approval, expiration, single use, changed parameters, and tamper evident session evidence.

This is a frontend browser demonstration. It is not production security enforcement. Session evidence resets on reload. Hash chained evidence is tamper evident, not immutable.

## Commands

```sh
npm install
npm run build
npx vitest run
npm run preview
```

The production site is generated in the dist directory. Executed test evidence is available at public/evidence/governance-tests.json.
